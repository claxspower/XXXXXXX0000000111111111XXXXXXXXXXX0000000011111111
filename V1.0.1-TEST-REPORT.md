# GsXFuscator V1.0.1 — Test report

## Fixed

- The original V1.0 source accepted `_VERSION == "Luau"` alone as Roblox host identification and used that marker to reset anti-debug scores and skip runtime identity audit checks.
- V1.0.1 requires multiple signals for advisory host classification, and **never** lets that classification suppress anti-debug, late-hook or runtime snapshot verification.
- The VM integrity error is neutral (`runtime verification failed`). Fake randomized Lua errors were intentionally not introduced.
- Transient SEAL4 decoder references continue to be released. No forced GC or coroutine wrapper is enabled by default.

## 1000-line Lua benchmark (native Lua 5.4 test machine)

- Original input: 14,016 bytes.
- V1.0.1 Sealed output: 374,034 bytes (26.69× expansion).
- Strong/compact compile + strict verification: ~3,256 ms.
- Protected program wall-clock execution, five runs: 1,116.65 / 1,124.25 / 1,099.78 / 1,079.12 / 1,137.14 ms; median **1,116.65 ms**.
- Plain program wall-clock execution in one run: ~1.55 ms.
- The protected execution time includes VM overhead, not just SEAL4 decoder time. These measurements are not Roblox/FiveM benchmarks.

## Not validated

- Native Lua 5.1 runtime (no executable available in the test environment).
- Actual Roblox/Luau client or FiveM runtime.
- Any claim that Clair, Luraph or another obfuscator was outperformed.
- A memory-dump-proof guarantee (not possible against a fully controlled host).
